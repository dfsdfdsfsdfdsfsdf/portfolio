# Ben Kidd — Technical Portfolio

Self-taught, hands-on in IT — Linux, networking, infrastructure, and software development. I'm looking for a formal role in the IT sector, and this repository is a living index of the projects, notes, and experiments I've built along the way.

I learn by building, breaking, and fixing things — running home servers, self-hosting services, writing software, and working through CTF boxes to understand how systems actually work (and fail).

This repo is organised around three areas, each proving a different set of fundamentals:

- **`homelab/`** — self-hosted infrastructure and networking projects, demonstrating sysadmin and networking fundamentals.
- **`coding/`** — software projects, demonstrating design and development skills beyond scripting.
- **`cybersecurity/`** — CTF writeups and security research, demonstrating a deeper understanding of how systems break, not just how to run them.

This repository will keep growing as I take on new projects and work toward a formal role in IT.
